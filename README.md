# 🏎️ 24 часа Ле-Мана

## Описание

(Немного изменила входные данные задачи, но суть не меняется)
Программа запрашивает у пользователя данные трёх гонщиков:
- имя;
- скорость в км/ч.

После ввода программа определяет победителя по расстоянию, которое гонщик преодолел за 24 часа.

## Возможности

- Добавление 3 гонщиков.
- Проверка имени на пустое значение.
- Проверка скорости:
    - значение не может быть пустым;
    - скорость должна быть числом;
    - скорость должна быть больше 0 и не превышать 250 км/ч.
- Вывод списка участников.
- Определение победителя.
- Вывод пройденного победителем расстояния за 24 часа.

### `Racer`
Класс, описывающий гонщика. Хранит его имя и скорость.

### `Winner`
Класс для определения победителя гонки. Получает список гонщиков, находит гонщика с максимальной скоростью и рассчитывает пройденное им расстояние
